# NEURD v0.2.0-preview.1 — local single-neuron research preview

This preview provides a focused local workflow for decomposing single-soma
neuronal meshes into somas, limbs, branches, skeletons and spine candidates.
It builds on [upstream NEURD](https://github.com/reimerlab/NEURD), with a narrower
geometry-processing scope and an explicit Python and batch interface.

## Start here

- [Source and overview](https://github.com/NEurosgen/NEURD/tree/v0.2.0-preview.1).
- [Notebook with saved results](https://github.com/NEurosgen/NEURD/blob/v0.2.0-preview.1/examples/h01_single_neuron.ipynb).
- [Viewing and rerun instructions](https://github.com/NEurosgen/NEURD/blob/v0.2.0-preview.1/examples/README.md).
- [Validated installation profile](https://github.com/NEurosgen/NEURD/blob/v0.2.0-preview.1/docs/INSTALLATION.md).

The release assets include a standalone HTML view and a compact example bundle
with the notebook, helper, reference observation and reviewed C03 meshes.
Saved results and the figure can be inspected without installing the scientific
environment. Processing requires the full tagged source, native dependencies
and a locally supplied raw neuron mesh.

## Included

- Validated `RunConfig` shared by the library API and batch runners, with explicit
  dataset, spine, refinement and SDF-ray settings.
- Separate mesh loading, segmentation and package-level geometry export, with
  supplied face mappings and provenance.
- Isolated batch workers with resource limits, failure reporting and verified
  resume of completed outputs.
- Bounded OFF parsing, sparse connected components, cKDTree coordinate matching,
  stable face-label grouping, buffered native CSV output, stage-boundary memory
  reclamation and derived mesh-cache clearing.
- A saved whole-H01 example documenting input fingerprints, configuration,
  geometry, exports, time, resident memory and environment.
- A supplementary manually reviewed spine illustration: C03 from H01 neuron
  `5319188363`, limb `000`, branch `150`. Its small meshes and face membership
  are bundled. The caption explicitly distinguishes this source from the timed
  neuron `2530864375`.

The notebook explains the implemented mechanisms and records one observed run.
It makes no comparative whole-pipeline speedup claim.

## Validation scope

Validation covers Linux x86_64 / Python 3.12.13, the constrained Python dependency
profile and an existing native development toolchain. Both required CGAL
providers were built locally. Checks include unit tests in a populated local
checkout, actual native SDF/MAP checks, branch processing and complete processing
of a 507,737-face / 253,307-vertex H01 reconstruction.

That recorded raw case retains one soma, five limbs, 28 branches and 18 candidate
regions, and exports 218 files. The saved notebook observation records
176.762 seconds for loading, segmentation and export, with kernel lifetime peak
RSS of 1.239 GiB. These values describe one input/configuration on the recorded
host; first-use JIT compilation is included and Jupyter startup contributes to
the RSS scope. The displayed C03 figure was subsequently regenerated from saved
geometry and the manually reviewed example, without repeating the timed pipeline.

Spine candidates can include mesh defects. Computational checks and one manually
reviewed illustration do not establish detection accuracy across a dataset.

## Source provenance

This publication removes obsolete credential-bearing files from the new branch's
history. The current code, example inputs and saved processing results are
unchanged. Commit identifiers embedded in saved execution metadata refer to the
original recording history and may not resolve in this sanitized release history.
For reproducibility, use the published tag and the recorded exact source, input
and environment hashes. The observations retain their original provenance.

## Known limitations

- Installation requires native development tools, MeshLab and Xvfb. The validated
  setup reused an existing native toolchain; a bare-OS installation and portable
  native binary distribution have not been established.
- Other operating systems, Python versions and dependency profiles need their
  own validation. An unconstrained installation changed the H01 geometry.
- Some tests use local inputs absent from a clean clone. Portable processing
  fixtures and a required native integration CI job remain release work; the
  existing CI runs the unit path.
- The complete raw H01 input is supplied locally. A verified remote acquisition
  recipe for a byte-identical copy is not provided. The small reviewed C03
  illustration is included with its provenance.
- Wider upstream workflows such as automated proofreading, cell typing and
  connectome analysis are outside this fork's supported geometry workflow.

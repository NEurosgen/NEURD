# Attribution and licensing status

This repository is a specialized research fork of
[NEURD by Brendan Celii and collaborators](https://github.com/reimerlab/NEURD).
The upstream framework and scientific algorithms are credited in the README and
publication notebook. Original copyright notices are retained, including the
notices in the inherited CGAL provider sources.

The intended license terms for the inherited Python and C++ code have not yet
been clarified with the upstream authors. This research preview assigns no new
license to that code. This notice records attribution and release status; it is
not a license grant.

The bundled H01 spine illustration is derived from data released by the
Lichtman laboratory at Harvard University and Google Connectomics. The
[official H01 release](https://h01-release.storage.googleapis.com/data.html)
licenses its datasets under
[Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/).
The example's source identities, mesh fingerprints, manual review and crop/mask
scope are recorded in
[its provenance](examples/data/h01_reviewed_spine/provenance.json).

See the [preview release notes](docs/releases/v0.2.0-preview.1.md) for the supported
workflow, validation scope and remaining release work.
